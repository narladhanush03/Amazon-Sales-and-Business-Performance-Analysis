# Amazon Sales and Business Performance Analysis

This project analyses Amazon sales data from January 2023 to December 2025 using SQL, Excel and Power BI.

The goal is to understand sales, profit, customers, products, discounts, delivery performance and returns.

## Tools Used

- PostgreSQL
- Microsoft Excel
- Power BI

## Project Workflow

```text
Raw dataset
   ↓
Data cleaning and validation
   ↓
SQL business analysis
   ↓
Excel MIS and Power BI dashboard
   ↓
Business findings and recommendations
```

## Main Work Completed

- Cleaned and validated 25,000 unique orders.
- Analysed monthly sales and profit.
- Compared categories and products.
- Analysed customers, discounts, ratings and payment methods.
- Reviewed delivery performance and return reasons.
- Built an Excel MIS and Power BI dashboard.

## Key Findings

- Delivered orders generated ₹309.96M in sales and ₹105.02M in profit.
- Electronics and Furniture generated approximately 72.23% of delivered sales.
- Monthly sales fluctuated across the analysis period.
- Occasional customers contributed the highest sales and profit by purchase frequency.
- Premium customers contributed the highest customer value.
- Returns were caused by several product, delivery, pricing and fulfilment issues.
